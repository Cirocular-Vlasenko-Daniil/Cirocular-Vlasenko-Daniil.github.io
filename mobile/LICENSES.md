# Лицензии / Licenses

10 minute zine использует сторонние шрифты и библиотеки. Ниже — что это, чьё и на каких условиях.
Полные тексты лицензий лежат рядом с файлами.

10 minute zine uses third-party fonts and libraries. Full license texts are included next to the files.

## Шрифты / Fonts

Все шрифты — из Google Fonts, по лицензии SIL Open Font License 1.1. Шрифтовые данные не изменены;
к некоторым файлам в конце дописаны нулевые байты, чтобы их читал PDF-движок (tools/fontfix.py).
При выгрузке PDF в документ встраивается подмножество глифов (для типографии — контуры букв) — лицензия это разрешает.

All fonts come from Google Fonts under the SIL Open Font License 1.1. Font data is unchanged;
some files have trailing zero bytes appended so the PDF engine can read them (tools/fontfix.py).
Exported PDFs embed glyph subsets (or glyph outlines for print shops), which the license permits.
